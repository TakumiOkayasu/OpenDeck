# 音量要件

音声の入力側と出力側の音量調整・表示に関する要求を管理する。全体の目的、操作の割り当て、利用環境、共通の品質要求は[全体要件](../requirements.md)を参照する。

## 目的

利用者が音声の入力側と出力側の音量を操作し、操作対象に対応する状態を把握できるようにする。

## 利用者の要求

| 要求 | 必要な振る舞い |
| --- | --- |
| 音量の変更 | 音声の入力側と出力側について、音量の上げ下げと、望む音量への変更ができる |
| 状態の把握 | 表示がどの操作対象に対応するか分かり、その対象の音量を把握できる |
| 共通の表現 | 音量を理解しやすい表現で把握・指定でき、対象が内部で使う表現や対象ごとの差を利用者が扱う必要がない |

入力手段への割り当ては、全体要件に従う。

## 要求の成立条件

| 確認する要求 | 利用者から観察できる成立条件 |
| --- | --- |
| 音量の変更 | 音声の入力側と出力側のそれぞれについて、選んだ対象の音量を変更できる |
| 状態の把握 | 音量の表示と操作対象の対応を判断でき、対象の音量を把握できる |
| 共通の表現 | 対象の内部表現を知らなくても、音量を把握・指定できる |

## 未確定の要求範囲

| 項目 | 確認する範囲 |
| --- | --- |
| 操作対象 | 音量を操作する対象の範囲と、選択の単位 |
| 表示先 | 状態を確認する場所と、表示に必要な情報 |
| 状態の変化 | 外部からの音量変更、対象の利用不能、復旧を利用者へどこまで反映するか |

音量固有の未確定事項は、その範囲を具体化する前に合意する。初期完成範囲と機能間の優先順位は、全体要件で扱う。
