# ボタン入力の要件

拡張がボタン入力の開始、継続、終了を利用するための要求を管理する。
共通の割り当てと利用環境は[全体要件](../requirements.md)に従う。

## 必要な振る舞い

- 拡張は入力の開始と終了を順に受け取り、現在も継続しているかを確認できる。
- 拡張は機器の取得方式や物理識別を知らずに、選択された入力を利用できる。
- 短押しや長押しの意味と成立条件は、その入力を利用する拡張が決める。
- 複数の入力が保持される間も、それぞれの状態を把握できる。
- 同時押しの継続と終了を利用できる。
- 入力が利用不能になったことと、正常に終了したことを区別できる。
- 既存の単発入力を利用する操作を継続して使える。

## 成立条件

開始から終了までの変化を、現在状態の照会と区別して把握できる。
利用不能になった入力を保持中と誤認せず、復旧後に古い入力を引き継がない。
拡張ごとに異なる長押しの解釈を選んでも、基盤や機器の実装を変更する必要がない。

回転の能力は、その能力を具体化する際に定める。
外部拡張の導入と既存形式の互換利用は[拡張利用の要件案](extensions.md)で扱う。
