# 回転入力の要件

[全体要件](../requirements.md)を前提に、回転でき、かつ押下できるノブの入力を利用する要求を管理する。
現行実装の対応済み機能を表すものではない。押下の開始・継続・終了は[ボタン入力の要件](buttons.md)に従う。

## 必要な振る舞い

- 利用側は、キー入力の監視や機器との接続を実装せず、機器から独立した回転の情報を利用できる。
- 押下と回転を独立した能力として利用でき、両方の能力を持つノブも利用対象に含める。
- 単発押下、通常の回転、押しながら回転する操作へ、それぞれ別の振る舞いを割り当てられる。
- 同じ物理ノブに属することを理由に、各操作を一つの実装へ集める必要がない。
- 押しながら回転する場合の挙動と判定方法は、その振る舞いを実現する実装へ閉じ込められる。
- 入力が利用不能になったことと、回転が発生していないことを区別できる。

## 成立条件

利用側が機器の識別子や取得方式を解釈せず、必要な回転の情報を扱える。
単発押下と回転に異なる操作を割り当て、操作の具体処理を基盤へ追加せずに利用できる。
押しながら回転する操作も、操作固有の挙動を共通仕様へ固定せずに実現できる。
入力の利用不能を正常な押下終了や回転停止と取り違えない。

## 未確定の範囲

必要な回転情報の表現・単位、値を伴う操作への受け渡しと割り当ての具体方式は、基本設計以降で定める。
押下・回転の情報を組み合わせる内部方式や同期方式は、各実装の責務とする。
押しながら回転した後に単発押下も実行するかは、基盤の共通動作に固定しない。
公開APIと実装の確認手順は[入力APIの対応計画](../plans/input-api.md)で扱う。
