# 音量の基本設計

[音量の要件](../requirements/volume.md)を具体化する際の、合意済みの公開表現を定める。
音量操作の実装はまだなく、入力から操作実行までの共通契約は[入力・実行の基本設計](../design.md)を参照する。

## 公開する値

音量として外部へ公開・設定する値は、0から100までの整数のパーセンテージとする。
操作対象の最大設定値を100%とする相対値として扱い、OSや機器が内部で使う最大値や表現を利用側へ持ち込まない。

これは音量に固有の契約である。汎用の読取・入力契約の返却型をパーセンテージへ固定しない。
OSや機器から取得する元の値と、音量として公開する値は別の境界で扱う。

## 具体化する範囲

対象との接続・状態取得・設定は副作用として分離し、取得済みの値の換算と検証は純粋な計算として扱う。
内部表現との換算、丸め、通知、取得値の鮮度は詳細設計で定める。
操作対象の種類や選択範囲は、音量要件の未確定事項を引き継ぐ。
